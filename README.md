## 🎯 Concept

The core idea is simple:

**A paper rocket travels through the hero section as the user scrolls.**

Instead of using autoplay animation, the entire flight is controlled directly by the user's scroll position.

As the paper rocket moves through the headline, each letter is progressively activated, creating a visual connection between **motion, typography, and user interaction**.

The experience is designed to feel like a creative digital landing page rather than a traditional website animation.

## 🎨 Design Direction

The visual language follows a minimal editorial style with:

- Warm cream/off-white background
- Large letter-spaced typography
- Strong whitespace
- Minimal interface elements
- Subtle technical/grid details
- Realistic folded-paper geometry
- Soft shadows and depth
- Restrained motion

The goal was to keep the **typography and interaction as the primary focus**, while the paper rocket acts as the visual storytelling element.
